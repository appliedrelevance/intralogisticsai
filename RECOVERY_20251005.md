### Script 1: "Pick to Receiving"
**Old name:** "Purchase Receipt - Move Bin to Receiving"
**New name:** "Pick to Receiving"
**DocType:** Purchase Receipt
**Event:** After Submit

**Full Script:**
```python
# Pick to Receiving
# Triggered when Purchase Receipt is submitted
# Checks system idle, finds bin with stock, then commands robot to move bin to receiving station

# Check system idle - all signals must be 0 except PLC_CYCLE_RUNNING
conn = frappe.get_doc("Modbus Connection", "Roots Intralogistics Learning Lab")
for signal in conn.signals:
    if signal.signal_name == "PLC_CYCLE_RUNNING":
        continue  # OK if running
    try:
        current_value = signal.read_signal()
        if current_value == 1 or current_value == True:
            frappe.throw(f"Robot system busy ({signal.signal_name} active). Wait for current operation to complete.")
    except:
        pass  # Skip signals that can't be read

# Find which bin has the items (simplified: use first item)
source_warehouse = None
for item in doc.items:
    # Query stock ledger to find which bin has this item
    bins = frappe.get_all(
        "Bin",
        filters={
            "item_code": item.item_code,
            "warehouse": ["like", "Storage Bin%"],
            "actual_qty": [">=", item.qty]
        },
        fields=["warehouse", "actual_qty"],
        order_by="actual_qty desc",
        limit=1
    )
    if bins:
        source_warehouse = bins[0].warehouse
        break

if not source_warehouse:
    frappe.throw("No storage bin found with sufficient stock for Purchase Receipt items")

# Find bin signal by warehouse name
bin_signal = None
for signal in conn.signals:
    if signal.warehouse == source_warehouse:
        bin_signal = signal
        break

# Find station signal by explicit signal name
station_signal = None
for signal in conn.signals:
    if signal.signal_name == "TO_RECEIVING_STA_1":
        station_signal = signal
        break

if not bin_signal:
    frappe.throw(f"No Modbus signal mapped to warehouse {source_warehouse}")
if not station_signal:
    frappe.throw("No Modbus signal found for TO_RECEIVING_STA_1")

# Write command signals
bin_signal.write_signal(True)
station_signal.write_signal(True)

frappe.msgprint(f"✅ Robot commanded to move {bin_signal.signal_name} to Receiving Station")
```

## 9. LESSONS LEARNED

### What NEVER to do again:
1. **NEVER run `./deploy.sh` on a running system** - it restores from old backup and wipes all changes
2. **NEVER run full restart when only frontend needs restart**
3. **ALWAYS create backup before major operations**

### Better approach for asset issues:
```bash
# Good: Restart only what's needed
docker compose restart frontend

# Bad: Nuclear option that destroys everything
./deploy.sh
```

### Production Requirements:
1. **Pre-built Docker image** with assets already compiled
2. **Separation of deployment vs. data restore**
3. **Backup automation** before any destructive operation
4. **Read-only golden master** that never gets overwritten
